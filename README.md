# Team Task Management System

This is a React project for managing team tasks, projects, deadlines, and progress in one place.

## Features

- Dashboard with task and project summary
- Login and register screens
- Task create, edit, delete, search, filter, and sort
- Project cards with progress and status
- Team members and activity updates
- Analytics charts
- Profile and settings pages
- Light and dark mode
- Responsive layout

## Tech Stack

- React
- Vite
- React Router
- Context API
- Recharts
- Lucide React
- CSS

## Run Locally

```bash
npm install
npm run dev
```

Then open the local URL shown in the terminal.
